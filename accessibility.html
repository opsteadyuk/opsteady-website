Accessibility

Accessibility statement

What we target

This site is built to meet WCAG 2.2 at Level AA, with body text held to the stricter AAA contrast ratio. That is the standard we design and test against for every page in this domain (opsteady.co.uk).

Scope

This statement covers the main Opsteady website only. The Health Check tool lives on its own subdomain, healthcheck.opsteady.co.uk, with its own codebase, and is not covered by this statement.

What's already true

  • A skip link is the first focusable element on every page.
  • Every page has a single H1 and proper landmark regions (header, nav, main, footer).
  • Focus is always visible — a 2px navy ring on the focused element, never suppressed.
  • Motion is disabled site-wide for anyone with prefers-reduced-motion set.
  • The language of the page is correctly set to British English.

Known issues

Honesty here matters more than a clean-looking page, so this list is real rather than empty.

A full keyboard-only navigation pass and screen reader pass across every page have not yet been completed and independently verified.

Target: before buying opens

Testing at 200% browser zoom and at a 320px viewport width has not yet been completed on every page.

Not every interactive element on every page has been individually checked against the 44 × 44px minimum target size.

Feedback

If any part of this site is hard to use with a keyboard, a screen reader, or any other assistive technology, tell us and we'll fix it. Email hello@opsteady.co.uk — we're a small operation and you'll hear back from a person, not a form response.

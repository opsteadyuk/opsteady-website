Cross-site structural system

Coherent without templated: some elements are byte-identical everywhere (nav, footer); some are a shared pattern applied with page-appropriate variation (proof, Health Check CTA, sequencing context); some deliberately do not recur at all (the ten-section product archetype belongs only to intervention pages). Forcing every page into the same section pattern was explicitly rejected — see the task's own instruction not to force identical section patterns everywhere.

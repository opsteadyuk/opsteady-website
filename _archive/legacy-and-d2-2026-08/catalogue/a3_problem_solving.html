Common questions

How is this different from Root Cause Analysis Toolkit (P7.5)?
They are not competing tools. The Root Cause Analysis Toolkit supplies the actual methods, 5 Whys, a fishbone diagram, a Pareto chart, used to work box 4 of the A3, the root cause box. This template is the structure that holds the whole problem from statement to verified follow-up, and enforces the sequence: nothing on the right side until the left side, including a verified root cause, is genuinely done. A verified cause from the Root Cause Analysis Toolkit is an input to this template's root-cause box, not a separate investigation running alongside it. See guide section 4 and section 10.
How do we know if something's worth an A3 versus a chartered Kaizen event?
Size and ownership are the test, the same fork used by Kaizen Event Planner & Charter Pack (P7.2) from its own side. A smaller, single-owner problem belongs here. A bigger, cross-functional opportunity, usually Value Stream Mapping's biggest named gap, is worth chartering as a full event instead. See guide section 10.
What actually counts as a root cause, versus a symptom we've stopped one step too early on?
Something systemic you can genuinely act on, a fixture, a schedule, an unclear standard, not a person. "The operator made a mistake" as a final answer almost always means you stopped one "why" too early. Keep asking until you reach something that, if you fixed it, would stop the problem recurring for anyone in that role, not just this one person this one time. See guide section 4 and section 14, failure 3.
Why "countermeasure" instead of "solution"?
Deliberate language. A solution implies you are finished. A countermeasure is your best current thinking, being tested, with a real date to check whether it actually held. If it does not, that is not a failed A3, it is the follow-up box doing exactly what it is there for. See guide section 4.
Do we need to be assigned a coach, or can we review our own A3s?
A second pair of eyes is what actually makes this work, not seniority. If nobody senior is available, any peer willing to ask "how do you know" before you cross to the right side does the job. Working genuinely alone, ask yourself the same three questions a coach would before crossing over. See guide section 3.

Common questions

What if corporate's already told us to digitise everything?
Run the test anyway, on every tracker they've flagged. It doesn't override the mandate, but it turns your response from blanket compliance or blanket resistance into a specific, evidenced case: this one genuinely clears the bar, this one doesn't, here's why. That's usually a far stronger conversation than either extreme. See guide section 5, fork 1, and section 17.
Doesn't staying on paper mean we're behind the times?
Not if the paper version is genuinely working. A board checked at a glance by anyone walking past, no login, no battery, costs nothing and loses nothing by staying physical. Modernisation and digitisation aren't the same thing, and the test exists precisely to tell them apart. See guide section 13 and section 17.
How do we know if a tracker "genuinely" needs digitising, rather than it just feeling like it should?
Check it against the 3 questions honestly: does someone who isn't physically there need it, does it need real calculation or trending that's a burden by hand, is the physical version itself actually failing. If none of these are genuinely true, "it feels like it should be digital" isn't a fourth reason. See guide section 2 and section 5.
What if we digitise something and then regret it?
Nothing here is permanent. Log the decision and reason at the time, and revisit it if the tracker's context changes materially, more volume, a new audience, a mandate that's shifted. A wrong call caught and corrected is far better than one nobody ever revisits. See guide section 8.
Do we need to run the test on every single tracker on site straight away?
No. Start with the one board everyone already assumes should be digital, since that's usually where the gap between assumption and evidence is biggest. Build the habit there before working through the rest. See guide section 7.

Common questions

What if our leadership team can't agree on 3 to 5 breakthroughs?
That disagreement is worth having openly rather than resolving by adding more breakthroughs until everyone's happy. Test each candidate against the question in section 14 of the Pro guide: would this happen anyway without deliberate resourcing? If the honest answer is yes, it's business as usual, not a breakthrough, and it can come off the list without anyone's function being dismissed. If real disagreement remains after that test, name who has the authority to make the final call, per section 4's decide-who's-involved prompts, and use it.
What if we don't have KPI Blueprint Map (F1.1) yet?
Don't try to build both at once. Run a lightweight version of this module using whatever your site already measures reliably, even if it isn't yet organised into a formal tree, and flag Blueprint Map as the next foundation to build. See Pro section 13's variant for a sequenced way to do both.
What if catchball just turns into a shouting match, or the opposite, everyone just agrees to be agreeable?
Both are signs the same underlying condition is missing: enough psychological safety for someone to say "that target isn't achievable" without it costing them. This module assumes Culture (F3) is in some working state first. If catchball keeps collapsing one way or the other, that's a Culture gap showing up here, not a flaw in the catchball method itself.
How is this different from just setting KPI targets at the start of the year?
A KPI target says what number you want. Hoshin Kanri says which few things are worth deliberately resourcing to move that number, tests the target against real capacity through catchball before it's fixed, and builds a review rhythm that changes what happens when it's off track. Setting a target alone skips the negotiation and the built-in response to drift.
What actually counts as a breakthrough, versus a normal annual priority?
A breakthrough changes the site's trajectory if achieved, and needs deliberate resource pulled from somewhere else to happen. If your site would pursue it anyway at the current pace with no extra resourcing decision, it's not a breakthrough, it's ongoing work that deserves its place in the daily KPIs, not the X-matrix.

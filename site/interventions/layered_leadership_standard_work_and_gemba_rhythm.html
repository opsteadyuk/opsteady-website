Layered Leadership Standard Work & Gemba Rhythm

**The mechanism.** Every leadership level above the supervisor walks the floor on its own rhythm, shift or area manager weekly, plant manager monthly, each with its own standard work for what that walk looks for. A senior walk isn't a bigger version of the supervisor's round, and it isn't re-checking the same boxes. It looks for whether the level below's own routine is genuinely happening, whether flagged items are actually closing, and for patterns that only become visible once you're looking across more than one shift or area at once.

Common questions

FAQ

Isn't this the same as Supervisor Standard Work Pack (P2.4)?

No, though it sits directly above it. P2.4 is one supervisor's own fixed round through their own single shift. This module is the leadership levels above the supervisor, each walking the floor on their own rhythm, each confirming the level below's routine is genuinely happening rather than re-walking the same checklist themselves. The split test was run explicitly before this was built, and the distinction holds. See the guide's opening note and section 9.

Isn't this the same as Layered Process Audit System (P2.6)?

They share the rotating-level mechanic, but check different things. P2.6 scores process and quality checkpoints against a written standard. This module checks leadership presence and follow-through, whether the level below's own routine is actually happening, whether flagged items close, and whether patterns only visible across shifts get caught. Run them as two distinct tools even on a site using both. See guide section 9.

Do we need Supervisor Standard Work Pack in place before we start this?

Yes. This module checks whether that routine is holding, it doesn't stand in for it. Build P2.4 first if it isn't already running. See guide section 3 and section 17.

What should a senior leader's walk actually be looking for, if not the same checklist as the supervisor?

Whether the level below's routine is genuinely being followed, real variation in their records rather than everything filled in at once. Whether flagged items from the last cycle actually closed. And patterns that only become visible once you're looking across more than one shift or area, which no single supervisor can see from inside their own. See guide section 2 and section 12.

What if a senior manager's own walk stops happening?

Treat it exactly the same as a missed round at any level, a system gap to name and close, not a discipline problem. It's also the single most common way this whole structure fails, since senior presence is usually the first thing to fade once an initiative's early momentum passes. See guide section 8 and section 15.

Common questions

FAQ

What if we don't have Skills Matrix data yet?

Estimate. Work out what the role genuinely needs to run safely and to standard, build the plan on that basis and go back to replace the estimate with the real coverage target once Skills Matrix exists for that area. Waiting for Skills Matrix before starting just delays a gap you can already see. See guide section 5.

How is this different from just cutting overtime?

Cutting overtime without knowing whether it's covering a genuine structural gap just moves the problem somewhere else, understaffed shifts or missed output, not away. This module sizes the gap first, so any decision about overtime is made against a known number rather than a guess. See guide section 17.

Isn't this just an HR headcount exercise?

Not if it's built properly. The plan only earns its keep once it's connected to the overtime and agency numbers it's meant to explain, which is why it's the baseline Overtime & Agency Spend Tracker measures against. A plan sitting disconnected from that spend is one of the ways this module dies. See guide section 9 and section 10.

We're constantly told the line is "covered." Why build this if nothing looks broken?

Because covered and correctly staffed aren't the same thing. Work getting done despite heavy overtime isn't proof the headcount is right, it's proof the gap is being paid for a different way, just not visibly. See guide section 17.

How big an area should we start with?

One, the highest-overtime area on site, not a site-wide rebuild. A detailed, sized gap for one real area beats a headcount total for the whole site with nothing actionable in it. See guide section 7.

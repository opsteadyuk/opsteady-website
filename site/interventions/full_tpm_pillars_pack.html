Full TPM Pillars Pack

This module is explicitly an expansion pack, not a replacement for the core asset-care modules a site should already have running: Downtime Tracking (P5.1), PM Schedule Builder (P5.2), Autonomous Maintenance (P5.4), and ideally OEE Management (P5.5). Common questions

FAQ

Do we need this module if we already have Autonomous Maintenance, PM, and OEE running?

Only if you want to go further, and only selectively. This module is explicitly an expansion pack, not a requirement, and it exists specifically for sites that have already stabilised those core modules and are wondering what, if anything, comes next. See Pro section 2.

How do we decide which of the remaining pillars to activate?

From your own ranked OEE loss tree or a documented risk, never from the fact that the classic eight-pillar model implies a pillar should eventually exist. If a candidate pillar doesn't trace back to a genuine, evidenced loss or risk on your own site, it doesn't get activated. See Pro section 5 and section 18's third fork.

Can we activate more than one pillar at a time if we have the resource?

The standard discipline is one at a time, proven before a second starts, and that's the right default for almost every site. Pro does allow piloting a second sooner in the specific case of genuinely confirmed spare capacity, such as a maintenance engineer with time specifically allocated to improvement work, but only once the first pillar has demonstrably held. See Pro section 14's variant.

Isn't Training and Education a whole new pillar we need to build?

Almost certainly not from scratch. For most sites, Skills Matrix (P1.1) and Training Plan & Competency Sign-off (P1.2) already substantially cover this pillar's ground. Check the coverage map honestly before assuming any pillar needs a new system built for it. See Pro section 5 and section 16's fifth failure.

What about Safety, Health and Environment? Do we build a separate TPM safety system?

No. This pillar must align with, not duplicate, your existing HSE System (E9.1). Running a parallel safety tracking mechanism under the TPM banner creates confusion about which system is actually authoritative. See Pro section 16's sixth failure.

Yamazumi / Line Balancing

This module builds a yamazumi chart, a simple stacked bar chart showing the actual work content at each station on a line or cell, and uses it to rebalance that work so it sits closer to takt, the target rate the line needs to run at. Yamazumi is a Japanese word meaning to pile up or stack, and the chart does exactly that: it stacks each station's individual work elements into a single bar, so every station's total load sits next to every other station's, measured against the same horizontal takt line.

TimeObserving and capturing real work content for a single line or cell, then building the first chart, usually takes a day or two of direct floor time. Trialling a rebalanced sequence before locking it as the new standard typically needs several full production cycles, not just a single walkthrough.
Who's involvedWhoever runs the line or cell being charted, since they know the real work content far better than any engineered standard sitting in a document. Someone who has already calculated takt or a clear target rate for this line, since the chart has no reference line without it.
MaterialsA stopwatch or timer, and a simple template, paper or a basic spreadsheet, capable of stacking observed times into a bar per station. No specialist time-study software is required.

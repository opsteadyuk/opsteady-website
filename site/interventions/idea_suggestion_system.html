Common questions

FAQ

We already ran a suggestion scheme and it died. Why would this one be different?

Name the actual difference: a real, kept response timescale on every idea, including declines, not just a fresh coat of paint on the same silent process. If the previous scheme's backlog is still sitting unanswered anywhere, clear it first, before asking anyone to believe this time is genuinely different. See guide section 6 and section 16.

What if we don't have capacity to action every idea people submit?

You don't need to accept every idea, you need to answer every idea. A declined suggestion with a real, written reason builds more trust in the scheme than silence does, since silence and a quiet no read identically from the submitter's side. See guide section 2 and section 4.

How is this different from Kaizen Event Planner & Charter Pack (P7.2)?

This module is the everyday, zero-friction channel for any idea, however small. A bigger idea, one that needs real budget, cross-functional resource or several protected days to run properly, graduates out of this tracker into a chartered event through Kaizen Event Planner instead, referencing the original idea's ID. Most ideas never need to graduate. See guide section 9 and section 17.

What if someone submits a complaint about a colleague rather than an idea?

Redirect it plainly. This scheme is for ideas about how work gets done, not a channel for raising a concern about an individual. Point to wherever that concern genuinely belongs on your site, and don't let it sit unanswered in this tracker either way. See guide section 16.

Do we need Culture (F3) built before we can run this?

In spirit, yes. This module's core mechanic, closing the loop honestly on every idea including declines, only works where genuine psychological safety already exists. Without it, submissions tend to drift toward complaints or blame instead of real ideas, and that's a Culture problem showing up here, not something a better tracker fixes on its own. See guide section 9 and section 15, failure 3.
